# AI Productivity Dashboard

Modern task dashboard built with:

- Next.js
- TypeScript
- Supabase
- Authentication
- Cloud Database

Features:

- Signup/Login
- Add/Edit/Delete Tasks
- Search + Filter
- Priority System
- Persistent Cloud Storage
- Responsive Dashboard
